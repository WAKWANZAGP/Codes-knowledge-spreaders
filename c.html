Important: What to Consider Before You Start Learning C
  • Mindset: C is foundational but can be strict. Start with simple programs, and read errors carefully.
  • Tools: Install a C compiler (gcc, clang, MSVC) and use a code editor or IDE (VS Code, Code::Blocks, etc).
  • Practice: Type and run every code sample, tweaking lines to see what changes.
  • Ask Questions: Get help or discuss in our community.
  • Take Notes: Note new concepts, syntax, and errors you solve.
  • Explore: Try building small projects like calculators, file readers, or games.
  • Debug: Use compiler warnings and debugging tools; always compile with -Wall.

C Notes & Topics

1. Introduction to C
  • C is a procedural, compiled programming language for systems, embedded, and application programming.
  • Files usually have .c extension.
  • It is the foundation for C++, Java, and many other languages.
2. Program Structure 
  • #include <stdio.h>
int main() {
  printf("Hello, World!\n");
  return 0;
}
  • All C programs start with main() function.
3. Variables and Data Types
  • Common types: int, float, double, char
  • int age = 21;
float temp = 36.6f;
double gpa = 3.89;
char grade = 'A';
4. Input and Output
  • Use printf() for output, scanf() for input.
  • int n;
printf("Enter a number: ");
scanf("%d", &n);
printf("You entered: %d\n", n);
5. Control Flow (if, else, switch) 
  • if (age >= 18) {
  printf("Adult\n");
} else {
  printf("Minor\n");
}
                
  • switch(day) {
  case 1:
    printf("Monday\n");
    break;
  default:
    printf("Other\n");
}
6. Loops (for, while, do-while) 
  • for (int i = 0; i < 5; i++) {
  printf("%d\n", i);
}
while (condition) {
  // code
}
do {
  // code
} while (condition);
7. Functions 
  • int add(int a, int b) {
  return a + b;
}
  • Declare functions before use, or use prototypes.
8. Arrays and Strings 
  • int arr[5] = {1,2,3,4,5};
printf("%d", arr[0]);
char name[20];
scanf("%s", name);
  • Strings are arrays of char ending with '\0'.
9. Pointers
  • Pointers store memory addresses; use * and &.
  • int x = 10;
int *p = &x;
printf("%d", *p); // 10
10. Structs 
  • struct Point {
  int x;
  int y;
};
struct Point p1 = {1, 2};
printf("%d", p1.x);
11. File I/O 
  • FILE *f = fopen("myfile.txt", "r");
if (f) {
  char line[100];
  while (fgets(line, sizeof(line), f)) {
    printf("%s", line);
  }
  fclose(f);
}
12. Best Practices & Resources
  • Use -Wall when compiling for warnings.
  • Keep code readable and well-commented.
  • Free dynamic memory (free()) to prevent leaks.
  • Explore: cppreference.com (C section)
  • Practice by solving problems and building small programs.
