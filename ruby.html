Important: What to Consider Before You Start Learning Ruby
  • Mindset: Ruby is expressive and elegant—aim to write code that's beautiful and readable!
  • Tools: Install Ruby and use editors like VS Code, RubyMine, or Sublime Text.
  • Practice: Run every code sample in irb (interactive Ruby) or a script file.
  • Ask Questions: Join our community for help and sharing ideas.
  • Take Notes: Track new methods, idioms, and error messages.
  • Explore: Try building small scripts or web apps with Ruby on Rails or Sinatra.
  • Debug: Use puts, p, and the Ruby debugger to inspect your code.

Ruby Notes & Topics

1. Introduction to Ruby
  • Ruby is a dynamic, interpreted, object-oriented language focused on simplicity and productivity.
  • Famous for web development (Ruby on Rails), scripting, and automation.
  • Files usually end with .rb.
2. Basic Syntax & Structure 
  • puts "Hello, Ruby!"
x = 10
y = 5
puts x + y
# This is a comment
  • No semicolons needed (unless multiple statements per line).
3. Variables and Data Types
  • Types: Integer, Float, String, Boolean, Array, Hash, Symbol
  • age = 21
temp = 36.6
name = "Sam"
active = true
arr = [1, 2, 3]
h = { name: "Sam", age: 21 }
  • Check type: name.class
4. Input and Output
  • Output: puts, print, p
  • Input: gets (returns string with newline, use .chomp to remove it)
  • print "Enter your name: "
name = gets.chomp
puts "Hello, #{name}!"
5. Control Flow (if, elsif, else, case) 
  • if age > 18
  puts "Adult"
elsif age == 18
  puts "Just became adult"
else
  puts "Minor"
end

case day
when "Monday"
  puts "Start of week"
else
  puts "Other day"
end
6. Loops (for, while, times, each) 
  • for i in 1..5
  puts i
end
i = 1
while i <= 5
  puts i
  i += 1
end
5.times { |i| puts i }
arr.each { |item| puts item }
7. Methods 
  • def add(a, b)
  a + b
end
puts add(2, 3)
  • Methods can have default and named arguments.
8. Arrays and Hashes 
  • arr = [1, 2, 3]
puts arr[0]
h = { "Alice" => 20, "Bob" => 25 }
puts h["Alice"]
9. Classes and Objects 
  • class Dog
  attr_accessor :name
  def bark
    puts "Woof!"
  end
end
d = Dog.new
d.name = "Max"
d.bark
  • Supports inheritance, modules (mixins), and metaprogramming.
10. File I/O 
  • File.open("file.txt", "r") do |f|
  f.each_line { |line| puts line }
end
11. Gems & Modules
  • Use gem install gemname to add libraries.
  • Require with require 'gemname'.
  • Find gems at rubygems.org
12. Best Practices & Resources
  • Write clear, idiomatic code. Use descriptive names and comments.
  • Explore docs: ruby-doc.org
  • Practice by building scripts, solving problems, or exploring Rails/Sinatra!
