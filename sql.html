SQL Notes & Topics

1. Introduction to SQL
  • SQL (Structured Query Language) is used for managing and querying relational databases.
  • Common for data analytics, business intelligence, and backend development.
  • Extensions: MySQL, PostgreSQL, SQLite, SQL Server, Oracle.
2. Basic Syntax & Structure
  • SQL statements end with a semicolon. Case-insensitive, but keywords are usually UPPERCASE.
  • SELECT 'Hello, SQL!' AS greeting;
  • Comments: -- single line, /* multi-line */
3. Creating and Altering Tables 
  • CREATE TABLE users (
  id INTEGER PRIMARY KEY,
  name TEXT,
  age INTEGER
);

ALTER TABLE users ADD COLUMN email TEXT;
  • Define columns, types, and constraints.
4. Inserting and Updating Data 
  • INSERT INTO users (name, age) VALUES ('Alice', 22);
UPDATE users SET age = 23 WHERE name = 'Alice';
  • Use DELETE FROM users WHERE ... to remove rows.
5. Basic Queries (SELECT, WHERE, ORDER BY, LIMIT) 
  • SELECT * FROM users;
SELECT name, age FROM users WHERE age > 20 ORDER BY age DESC LIMIT 5;
  • Use WHERE for filtering, ORDER BY for sorting, LIMIT to restrict results.
6. Joins (INNER, LEFT, RIGHT, FULL) 
  • SELECT u.name, o.amount
FROM users u
INNER JOIN orders o ON u.id = o.user_id;
  • Other joins: LEFT JOIN, RIGHT JOIN, FULL OUTER JOIN
7. Aggregation (COUNT, SUM, AVG, GROUP BY, HAVING) 
  • SELECT COUNT(*) FROM users;
SELECT AVG(age) FROM users;
SELECT age, COUNT(*) FROM users GROUP BY age HAVING COUNT(*) > 1;
8. Subqueries & Nested SELECTs 
  • SELECT name FROM users WHERE age = (SELECT MAX(age) FROM users);
  • Subqueries can be used in SELECT, WHERE, FROM clauses.
9. Indexes, Constraints & Keys 
  • CREATE INDEX idx_name ON users(name);
ALTER TABLE users ADD CONSTRAINT unique_email UNIQUE(email);
  • Primary keys, foreign keys, unique, not null, check constraints.
10. Transactions 
  • BEGIN TRANSACTION;
UPDATE users SET age = age + 1;
COMMIT;
  • Use ROLLBACK; to undo.
11. Views & Stored Procedures 
  • CREATE VIEW adult_users AS SELECT * FROM users WHERE age >= 18;
  • Stored procedures and functions are supported in some DBMSs (e.g., MySQL, PostgreSQL).
12. Best Practices & Resources
  • Use clear table/column names, keep queries readable and efficient.
  • Backup your database before making major changes.
  • Read docs: sqltutorial.org | sqlstyle.guide
  • Practice by writing and running your own queries!
