Elixir Notes & Topics

1. Introduction to Elixir
  • Elixir is a functional, concurrent language that runs on the Erlang VM (BEAM).
  • Ideal for scalable, fault-tolerant systems—think chat, IoT, distributed apps.
  • Syntax is friendly, inspired by Ruby.
2. Getting Started & Basic Syntax
  • Use iex (Elixir REPL) for interactive learning.
  • IO.puts("Hello, Elixir!")
a = 5 + 3
  • Every variable is immutable.
3. Data Types
  • Types: integers, floats, booleans, atoms (:ok), strings, lists, tuples, maps.
  • name = "Sam"
nums = [1, 2, 3]
coords = {4, 5}
info = %{name: "Sam", age: 20}
4. Pattern Matching
  • Use = for pattern matching, not assignment.
  • {a, b} = {1, 2}  # a = 1, b = 2
[x, y | rest] = [1,2,3,4]  # x=1, y=2, rest=[3,4]
5. Functions
  • Define with def inside a defmodule.
  • defmodule Math do
  def add(a, b), do: a + b
end

Math.add(2, 3)
  • Supports pattern matching and guards in function heads.
6. Control Flow 
  • if age >= 18 do
  IO.puts("Adult")
else
  IO.puts("Minor")
end

case day do
  "Mon" -> IO.puts("Monday")
  _ -> IO.puts("Other")
end
7. Lists, Tuples, Maps 
  • nums = [1, 2, 3]
IO.inspect(Enum.map(nums, fn x -> x * 2 end))

coords = {3, 4}
info = %{name: "Sam", age: 20}
8. Recursion & Enum
  • Recursion is used instead of loops.
  • Collections are transformed with Enum and Stream modules.
  • Enum.reduce([1,2,3], 0, fn x, acc -> x + acc end)
Enum.filter(1..10, fn x -> rem(x, 2) == 0 end)
9. Processes & Concurrency
  • Elixir uses lightweight processes for concurrency (not OS processes).
  • spawn(fn -> IO.puts("Hello from a process!") end)
send(self(), :ping)
receive do
  :ping -> IO.puts("Pong!")
end
  • Learn about OTP for robust concurrent systems.
10. Mix & Project Structure
  • Use mix new projectname to scaffold projects.
  • Run tests: mix test
  • Dependencies are managed in mix.exs.
11. Phoenix Framework
  • Phoenix is Elixir's web framework for APIs and real-time apps.
  • Generate a new Phoenix app with mix phx.new appname.
  • Explore Channels for WebSockets and LiveView for interactive UIs.
12. Best Practices & Resources
  • Write idiomatic, functional code—avoid side effects and mutable data.
  • Explore docs: elixir-lang.org/learning.html
  • Practice with small projects and code katas.
  • Try building distributed, fault-tolerant apps to unlock Elixir's power!
