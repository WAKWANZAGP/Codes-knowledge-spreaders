MATLAB Notes & Topics

1. Introduction to MATLAB
  • What is MATLAB? Matrix Laboratory; a high-level language for numerical computing.
  • Main uses: Data analysis, visualization, engineering, simulations, algorithms.
  • First steps: Opening MATLAB, using the Command Window.
2. Variables and Data Types
  • Creating variables: x = 5;, name = 'Alice';
  • Basic data types: numeric, char, string, logical, array, cell, struct
  • Type conversion: double('5'), num2str(123)
3. Input and Output
  • Printing: disp('Hello, world!')
  • User input: name = input('Enter your name: ','s')
4. Matrices and Arrays
  • MATLAB is built for matrix operations: A = [1 2; 3 4];
  • Indexing: A(1,2)
  • Common functions: size(), length(), sum(), mean()
5. Control Flow (if, else, switch)
  • Conditional statements: if, elseif, else, switch
  • Relational operators: ==, ~=, <, >
  • Example:
    if age >= 18
      disp('Adult')
    else
      disp('Minor')
    end
6. Loops (for, while)
  • for i = 1:5 — Repeat actions a fixed number of times
  • while condition — Repeat while a condition is true
  • Breaking and continuing loops: break, continue
7. Functions
  • Defining: function y = add(a,b), y = a+b; end
  • Calling: result = add(3,4);
  • Multiple outputs, input arguments, and local variables
8. Scripts and M-files
  • Scripts: Saved with .m extension, run all commands in file
  • Functions: Also .m files, start with function keyword
  • Best practice: Use scripts for simple tasks, functions for reusable code
9. Plotting and Visualization
  • Basic plotting: plot(x, y), xlabel(), ylabel(), title()
  • Other plots: bar(), histogram(), scatter()
  • Customizing plots (colors, legends, grid)
10. File I/O
  • Reading/writing data: load, save, csvread, csvwrite, fopen, fscanf, fprintf
  • Importing/exporting variables and data
