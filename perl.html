Important: What to Consider Before You Start Learning Perl
  • Mindset: Perl is flexible and expressive—there are many ways to solve a problem!
  • Tools: Install Perl (usually pre-installed on Unix/Linux), use an editor like VS Code, Vim, or Atom.
  • Practice: Run code snippets with perl script.pl or try them in an online Perl REPL.
  • Ask Questions: Join our community for Perl help and discussion.
  • Take Notes: Track new idioms, regular expression tricks, and error messages.
  • Explore: Try small scripts for text processing, system automation, or web tasks.
  • Debug: Use warnings and strict pragmas, and the perl -c syntax checker.

Perl Notes & Topics

1. Introduction to Perl
  • Perl is a high-level, interpreted language known for text processing and system scripting.
  • Famous motto: "There's more than one way to do it."
  • Files usually end with .pl.
2. Basic Syntax & Structure 
  • #!/usr/bin/perl
use strict;
use warnings;
print "Hello, Perl!\n";
  • Use use strict; and use warnings; for good habits.
3. Variables and Data Types
  • Scalars: $a = 5;
    Arrays: @arr = (1, 2, 3);
    Hashes: %h = (a=>1, b=>2);
  • Context matters: arrays/lists in list context, scalars in scalar context.
4. Input and Output 
  • print "Enter your name: ";
my $name = ;
chomp $name;
print "Hello, $name!\n";
  • Use chomp to remove trailing newline from input.
5. Control Flow (if, else, unless, given) 
  • if ($a > 10) {
  print "Big\n";
} elsif ($a == 10) {
  print "Ten\n";
} else {
  print "Small\n";
}
unless ($a) { print "Zero!\n"; }
  • Switch-like given is available in Perl 5.10+.
6. Loops (for, foreach, while, until) 
  • for (my $i=0; $i<5; $i++) {
  print "$i\n";
}
foreach my $item (@arr) {
  print "$item\n";
}
while () {
  last if $_ eq "exit\n";
  print $_;
}
7. Subroutines 
  • sub add {
  my ($a, $b) = @_;
  return $a + $b;
}
print add(2,3);
  • Arguments are passed in @_.
8. Regular Expressions 
  • my $str = "hello";
if ($str =~ /ell/) {
  print "Found!\n";
}
$str =~ s/ell/ALL/;
  • Powerful and central to Perl scripting.
9. File I/O 
  • open(my $fh, "<", "file.txt") or die "Can't open file!";
while (my $line = <$fh>) {
  print $line;
}
close($fh);
10. References and Complex Data 
  • my $arr_ref = [1,2,3];
my $hash_ref = {a=>1, b=>2};
print $arr_ref->[0];
print $hash_ref->{a};
  • References are like pointers to arrays/hashes.
11. Modules and CPAN
  • Use modules with use Module::Name;
  • Install more from CPAN for huge library access.
12. Best Practices & Resources
  • Always use strict and warnings for safety.
  • Check docs: perldoc.perl.org
  • Practice with small scripts and text processing challenges!
