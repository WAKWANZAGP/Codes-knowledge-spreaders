Important: What to Consider Before You Start Learning Swift
  • Mindset: Swift is modern, safe, and expressive. It's the main language for iOS/macOS development.
  • Tools: Install Xcode on macOS or use SwiftFiddle in your browser.
  • Practice: Code in Playgrounds (Xcode) or try examples on your own device.
  • Ask Questions: Use our community for help and support.
  • Take Notes: Record new syntax, concepts, and error messages.
  • Explore: Try building small iOS/macOS apps, scripts, or command-line tools.
  • Debug: Use print() and Xcode's debugger to inspect your code.

Swift Notes & Topics

1. Introduction to Swift
  • Swift is a fast, modern, type-safe language for iOS, macOS, watchOS, and tvOS development.
  • Files usually end with .swift.
2. Basic Syntax & Structure 
  • print("Hello, Swift!")
let x = 10
var y = 5
print(x + y)
  • Single-line comments: // comment, multi-line: /* ... */
3. Variables and Data Types
  • Types: Int, Double, String, Bool, Array, Dictionary
  • let age: Int = 21
var temp = 36.6
let name = "Sam"
let isActive = true
let arr = [1, 2, 3]
let dict = ["name": "Sam", "age": "21"]
  • Check type: type(of: variable)
4. Input and Output
  • Output: print()
  • Input: readLine() for console input (in CLI apps)
  • print("Enter your name: ", terminator: "")
if let name = readLine() {
    print("Hello, \(name)!")
}
5. Control Flow (if, switch) 
  • if age >= 18 {
    print("Adult")
} else {
    print("Minor")
}

switch day {
case "Monday":
    print("Start of week")
default:
    print("Other day")
}
6. Loops (for, while, repeat-while) 
  • for i in 1...5 {
    print(i)
}
var i = 1
while i <= 5 {
    print(i)
    i += 1
}
repeat {
    print(i)
    i += 1
} while i <= 5
7. Functions 
  • func add(a: Int, b: Int) -> Int {
    return a + b
}
print(add(a: 2, b: 3))
  • Supports default, variadic, and inout arguments.
8. Arrays and Dictionaries 
  • let arr = [1, 2, 3]
print(arr[0])
let ages = ["Alice": 20, "Bob": 25]
print(ages["Alice"] ?? "Unknown")
9. Classes, Structs, and Enums 
  • class Dog {
    var name: String
    init(name: String) { self.name = name }
    func bark() { print("Woof!") }
}
let d = Dog(name: "Max")
d.bark()

struct Point {
    var x: Int
    var y: Int
}
let p = Point(x: 1, y: 2)

enum Color { case red, green, blue }
  • Supports inheritance (for classes), protocols, and value/reference types.
10. Optionals & Safe Unwrapping 
  • var name: String? = nil
if let n = name {
    print(n)
} else {
    print("No name")
}
  • Use ? for optional types; ?? for default values.
11. Closures & Higher-Order Functions 
  • let nums = [1,2,3]
let doubled = nums.map { $0 * 2 }
let even = nums.filter { $0 % 2 == 0 }
12. Best Practices & Resources
  • Use descriptive names and idiomatic Swift code.
  • Explore docs: docs.swift.org/swift-book/
  • Practice by building small apps and experimenting with Playgrounds!
