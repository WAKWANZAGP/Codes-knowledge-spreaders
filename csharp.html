Important: What to Consider Before You Start Learning C#
  • Mindset: C# is powerful for app, game, and enterprise development. Stay curious and patient as you learn its syntax and structure.
  • Tools: Install .NET SDK and use an IDE like Visual Studio, VS Code, or JetBrains Rider.
  • Practice: Type out and run the example code, don't just read or watch.
  • Ask Questions: Share your challenges and ideas in our community.
  • Take Notes: Document key concepts, syntax, and errors you face to speed up your learning.
  • Explore: Try building small projects or games (Unity uses C#) to solidify your knowledge.
  • Debug: Make use of IDE debugging tools and read error messages carefully.

C# Notes & Topics

1. Introduction to C#
  • C# is a modern, object-oriented programming language developed by Microsoft.
  • Used for Windows apps, games (Unity), web APIs, and enterprise software.
  • Runs on .NET (Windows, Linux, macOS).
2. Structure of a C# Program
  • Every C# program has at least one class and a Main method.
  • using System;
class Program {
  static void Main() {
    Console.WriteLine("Hello World!");
  }
}
3. Variables and Data Types
  • Common types: int, double, string, bool, char
  • int age = 20;
double price = 9.99;
string name = "Sam";
bool isActive = true;
4. Input and Output
  • Output: Console.WriteLine("Hello!");
  • Input: string input = Console.ReadLine();
  • Convert input: int num = int.Parse(input);
5. Control Flow (if, else, switch) 
  • if (age >= 18) {
  Console.WriteLine("Adult");
} else {
  Console.WriteLine("Minor");
}
                
  • switch(day) {
  case "Monday":
    // code
    break;
  default:
    // code
    break;
}
6. Loops (for, while, foreach) 
  • for (int i = 0; i < 5; i++) {
  Console.WriteLine(i);
}

while (condition) {
  // code
}

foreach (var item in collection) {
  // code
}
7. Methods (Functions) 
  • static int Add(int a, int b) {
  return a + b;
}
  • Methods can have parameters, return types, and can be static or instance methods.
8. Arrays and Lists 
  • int[] numbers = {1, 2, 3};
Console.WriteLine(numbers[0]); // 1
                
  • using System.Collections.Generic;
List<string> names = new List<string>();
names.Add("Alice");
9. Classes and Objects 
  • class Dog {
  public string Name;
  public void Bark() {
    Console.WriteLine("Woof!");
  }
}
Dog d = new Dog();
d.Name = "Max";
d.Bark();
  • Understand fields, methods, and instantiation.
10. Exception Handling 
  • try {
  int x = int.Parse("abc");
} catch (FormatException e) {
  Console.WriteLine("Error: " + e.Message);
} finally {
  Console.WriteLine("Done!");
}
  • Always handle exceptions for robust programs.
11. Advanced Features
  • Properties & Encapsulation, Inheritance, Interfaces, LINQ, Generics, and Events.
  • Explore async/await for asynchronous programming.
12. Best Practices & Resources
  • Follow C# naming conventions (PascalCase for types and methods).
  • Keep code DRY and well-commented.
  • Explore docs: Microsoft C# Docs
  • Practice building small apps to reinforce concepts.
