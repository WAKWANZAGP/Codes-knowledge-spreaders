Scratch Programming Class
Important: What to Consider Before You Start Learning Scratch
  • Mindset: Scratch is visual and block-based. Be creative and don’t be afraid to explore.
  • Tools: Go to scratch.mit.edu and use the online editor. You can also download Scratch Desktop.
  • Practice: Drag, drop, and snap blocks to build projects. Try to remix projects you find in the Scratch community.
  • Ask Questions: Join our community or the Scratch community to discuss and share projects.
  • Take Notes: Save and document your favorite blocks, scripts, and creative ideas.
  • Stay Curious: Explore animations, games, stories, and interactive art as you learn.
  • Don’t Fear Errors: If something doesn’t work, try changing blocks or checking the order of your scripts.

Scratch Notes & Topics

1. Introduction to Scratch
  • What is Scratch? A block-based programming language for creating interactive stories, games, and animations.
  • Main uses: Learning programming logic, creativity, and sharing projects.
  • How to start: Create an account on Scratch and explore featured projects.
2. The Scratch Interface
  • Stage, sprites, block palette, scripting area, and backdrop.
  • How to add, delete, and edit sprites and backdrops.
  • Saving and sharing your projects.
3. Motion and Looks Blocks
  • Moving sprites with motion blocks (move, turn, go to, glide).
  • Changing appearance using looks blocks (say, think, show, hide, switch costume).
4. Events and Control Blocks
  • Starting scripts with events (when green flag clicked, when this sprite clicked, key pressed).
  • Control structures: wait, repeat, forever, if, if-else, stop.
5. Sensing and Operators
  • Sensing blocks: detect mouse, touching, key pressed, ask and wait.
  • Operators: math, logic, string manipulation.
6. Variables and Lists
  • Creating variables for storing data (score, timer, etc.).
  • Using lists for collections (high scores, inventory, etc.).
7. Custom Blocks (My Blocks)
  • Creating custom blocks to reuse code.
  • Using arguments and organizing scripts.
8. Sound and Music
  • Adding sounds and music to your projects.
  • Using sound blocks to play, stop, and change volume.
9. Drawing and Pen Blocks
  • Using pen blocks to draw on the stage (pen down, pen up, set pen color).
  • Making art and visual effects with code.
10. Cloning and Broadcasts
  • Making and managing sprite clones (create clone, delete clone).
  • Using broadcasts to coordinate actions between sprites.
11. Game Design in Scratch
  • Building simple games: logic, scoring, win/lose conditions.
  • Collision detection, timers, and user interface elements.
12. Sharing and Remixing Projects
  • Publishing your project to the Scratch community.
  • Remixing others’ projects and giving credit.
  • Participating in studios and Scratch events.
