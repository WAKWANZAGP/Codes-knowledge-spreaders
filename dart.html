Dart Notes & Topics

1. Introduction to Dart
  • Dart is a modern, object-oriented language by Google, great for web and mobile (Flutter) apps.
  • Easy to learn if you know JavaScript, Java, or C#.
  • Try it online at DartPad.
2. Program Structure
  • Dart programs start with void main() function.
  • void main() {
  print('Hello, Dart!');
}
3. Variables and Data Types
  • Use var, final, const, or explicit types (int, double, String, bool).
  • var name = 'Alice';
int age = 20;
final pi = 3.14;
const planet = 'Earth';
4. Input and Output
  • Use print() for output.
  • For input (console), use dart:io: 
    import 'dart:io';
void main() {
  String? name = stdin.readLineSync();
  print('Hello, $name!');
}
5. Control Flow (if, else, switch) 
  • if (age >= 18) {
  print('Adult');
} else {
  print('Minor');
}
                
  • switch(day) {
  case 'Monday':
    print('Start of week');
    break;
  default:
    print('Other day');
}
6. Loops (for, while, do-while, for-in) 
  • for (int i = 0; i < 3; i++) {
  print(i);
}
while (condition) { ... }
do { ... } while (condition);
for (var item in list) { ... }
7. Functions 
  • int add(int a, int b) {
  return a + b;
}
var sum = add(2, 3);
  • Arrow syntax: int sqr(int n) => n * n;
  • Optional and named parameters supported.
8. Lists, Sets, and Maps 
  • var numbers = [1, 2, 3];
numbers.add(4);

var fruits = {'apple', 'banana'};
var ages = {'Alice': 20, 'Bob': 25};
9. Classes and Objects 
  • class Person {
  String name;
  int age;
  Person(this.name, this.age);

  void greet() => print('Hi, I am $name.');
}
var p = Person('Alice', 20);
p.greet();
10. Null Safety
  • By default, variables can't be null unless marked nullable with ?.
  • String? name = null;
if (name != null) { print(name.length); }
  • Use the ! operator to assert not-null (use carefully).
11. Async Programming
  • Use Future and async/await for asynchronous code.
  • Future fetchData() async {
  await Future.delayed(Duration(seconds: 2));
  print('Data loaded!');
}
12. Best Practices & Resources
  • Use clear names and keep code tidy.
  • Explore: dart.dev/guides
  • Practice by making small apps and experimenting.
  • Try Flutter for building mobile and web UIs with Dart!
