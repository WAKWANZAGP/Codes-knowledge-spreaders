Important: What to Consider Before You Start Learning Objective-C
  • Mindset: Objective-C is a superset of C with object-oriented features. Expect to write both C and OO code!
  • Tools: Install Xcode (macOS only), use its editor and Interface Builder for projects.
  • Practice: Build small iOS/macOS apps or try examples in Xcode Playgrounds.
  • Ask Questions: Use our community for help and support.
  • Take Notes: Write down syntax, error messages, and memory management tips.
  • Explore: Try mixing C and Objective-C, and look at Apple frameworks (Foundation, UIKit, AppKit).

Objective-C Notes & Topics

1. Introduction to Objective-C
  • Objective-C is a dynamic, object-oriented superset of C, mainly used for Apple platforms.
  • Files use .m (implementation), .h (header), and .mm (Objective-C++) extensions.
2. Basic Syntax & Structure 
  • #import <Foundation/Foundation.h>

int main(int argc, const char * argv[]) {
    @autoreleasepool {
        NSLog(@"Hello, Objective-C!");
    }
    return 0;
}
  • Single-line comments: // comment, multi-line: /* ... */
3. Variables and Data Types
  • Primitive: int, float, char, BOOL
  • Objects: NSString *, NSNumber *, NSArray *, NSObject *
  • int age = 21;
float temp = 36.6;
NSString *name = @"Sam";
BOOL active = YES;
NSArray *arr = @[@1, @2, @3];
4. Input and Output
  • Console output: NSLog(@"Text");
  • Input: Use scanf (C) or UI elements in apps.
  • char name[50];
printf("Enter your name: ");
scanf("%s", name);
NSLog(@"Hello, %s!", name);
5. Control Flow (if, switch) 
  • if (age >= 18) {
    NSLog(@"Adult");
} else {
    NSLog(@"Minor");
}

switch(day) {
    case 1:
        NSLog(@"Monday");
        break;
    default:
        NSLog(@"Other day");
}
6. Loops (for, while, for-in) 
  • for (int i = 0; i < 5; i++) {
    NSLog(@"%d", i);
}
int i = 1;
while (i <= 5) {
    NSLog(@"%d", i);
    i++;
}
for (NSNumber *n in arr) {
    NSLog(@"%@", n);
}
7. Methods & Functions 
  • - (int)add:(int)a to:(int)b {
    return a + b;
}
+ (void)classMethod { ... }
  • Instance methods use -, class methods use +.
8. Classes and Objects 
  • @interface Dog : NSObject
@property NSString *name;
- (void)bark;
@end

@implementation Dog
- (void)bark { NSLog(@"Woof!"); }
@end

Dog *d = [[Dog alloc] init];
d.name = @"Max";
[d bark];
  • Use @interface and @implementation for classes.
9. Memory Management
  • ARC (Automatic Reference Counting) manages most memory automatically.
  • Use strong, weak, assign for properties.
  • @property (nonatomic, strong) NSString *name;
10. Collections (NSArray, NSDictionary, NSSet) 
  • NSArray *arr = @[@1, @2, @3];
NSDictionary *dict = @{@"Alice": @20, @"Bob": @25};
NSLog(@"%@", arr[0]);
NSLog(@"%@", dict[@"Alice"]);
11. Protocols & Categories 
  • @protocol Drivable
- (void)drive;
@end

@interface Car : NSObject 
- (void)drive { NSLog(@"Vroom!"); }
@end

// Category
@interface NSString (Reverse)
- (NSString *)reverseString;
@end
  • Protocols are like interfaces; categories add methods to existing classes.
12. Best Practices & Resources
  • Use clear naming, ARC memory management, and Apple's Foundation/Cocoa frameworks.
  • Check docs: Apple Objective-C Guide
  • Practice by building small apps and exploring frameworks!
