  • Ask Questions: Join our community for help and discussion.
  • Take Notes: Write down useful idioms, error messages, and library functions.
  • Explore: Try building scripts, web servers, or Spark data pipelines.

Scala Notes & Topics

1. Introduction to Scala
  • Scala is a concise, statically-typed language for JVM combining OOP and functional programming.
  • Great for data engineering, web backends, and scalable systems.
  • Files usually end with .scala.
2. Basic Syntax & Structure
  • Scripts run in REPL or as object Main { def main(args: Array[String]) { ... } }
  • object Hello {
  def main(args: Array[String]): Unit = {
    println("Hello, Scala!")
  }
}
  • Single-line comments: // comment, Multi-line: /* ... */
3. Variables and Data Types 
  • val x: Int = 5 // immutable
var y = 10     // mutable, type inferred
val name: String = "Sam"
val f: Double = 2.71
  • Types: Int, Double, String, Boolean, List, Map, etc.
4. Input and Output
  • Output: println("Text")
  • Input: scala.io.StdIn.readLine()
  • print("Enter your name: ")
val name = scala.io.StdIn.readLine()
println(s"Hello, $name!")
5. Control Flow (if, match/case) 
  • if (x > 0) println("Positive")
else if (x == 0) println("Zero")
else println("Negative")

day match {
  case "Monday" => println("Start of week")
  case _        => println("Other day")
}
6. Loops (for, while, do-while) 
  • for (i <- 1 to 5) println(i)
var i = 1
while (i <= 5) { println(i); i += 1 }
do { println(i); i += 1 } while (i <= 5)
  • Prefer collections and higher-order functions over loops.
7. Functions 
  • def add(a: Int, b: Int): Int = a + b
val sqr = (x: Int) => x * x
  • Supports default/named args and higher-order functions.
8. Collections (List, Map, Set) 
  • val nums = List(1,2,3)
val ages = Map("Alice" -> 20, "Bob" -> 21)
val s = Set(1,2,3)
nums.map(_ * 2)
ages.get("Alice")
  • Immutable by default; use mutable for mutable versions.
9. Classes and Case Classes 
  • class Person(val name: String, var age: Int)
val p = new Person("Sam", 21)
case class Point(x: Int, y: Int)
val pt = Point(1,2)
  • Case classes are for immutable data and pattern matching.
10. Traits and Inheritance 
  • trait Greeter { def greet(): Unit }
class Person(name: String) extends Greeter {
  def greet() = println(s"Hi, I'm $name")
}
  • Traits are like interfaces with default implementations.
11. Pattern Matching & Option 
  • val opt: Option[Int] = Some(5)
opt match {
  case Some(value) => println(value)
  case None        => println("No value")
}
  • Pattern matching is powerful in Scala.
12. Best Practices & Resources
  • Favor immutability and expressive, concise code.
  • Explore docs: docs.scala-lang.org
  • Practice by building scripts, data pipelines, or functional projects!
