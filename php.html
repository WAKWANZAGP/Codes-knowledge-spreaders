PHP Notes & Topics

1. Introduction to PHP
  • PHP is a widely-used open-source scripting language especially for web development.
  • Runs on the server and outputs HTML to the browser.
  • Files typically end with .php.
2. Basic Syntax & Structure
  • PHP code is written inside <?php ... ?> tags.
  • <?php
echo "Hello, PHP!";
?>
  • Every statement ends with a semicolon (;).
3. Variables and Data Types
  • All variables start with $ (e.g., $name).
  • Types: int, float, string, bool, array, object, null
  • $name = "Alice";
$age = 21;
$isActive = true;
$height = 1.70;
4. Input and Output
  • Output: echo "Text"; or print "Text";
  • Input (web): use $_GET, $_POST, $_REQUEST
  • <form method="post">
  <input name="username">
  <button>Send</button>
</form>
<?php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
  $user = $_POST["username"];
  echo "Hello, $user!";
}
?>
5. Control Flow (if, else, switch) 
  • if ($age >= 18) {
  echo "Adult";
} else {
  echo "Minor";
}

switch ($day) {
  case "Monday":
    echo "Start of week";
    break;
  default:
    echo "Other day";
}
6. Loops (for, while, foreach) 
  • for ($i = 0; $i < 5; $i++) {
  echo $i;
}
while ($condition) { ... }
foreach ($arr as $item) { ... }
7. Functions 
  • function add($a, $b) {
  return $a + $b;
}
$res = add(2, 3);
  • Supports default, variable, and reference arguments.
8. Arrays and Associative Arrays 
  • $arr = [1, 2, 3];
echo $arr[0];
$ages = ["Alice" => 20, "Bob" => 25];
echo $ages["Alice"];
9. Objects and Classes 
  • class Dog {
  public $name;
  function bark() {
    echo "Woof!";
  }
}
$d = new Dog();
$d->name = "Max";
$d->bark();
  • Supports constructors, inheritance, and visibility (public/private/protected).
10. File I/O 
  • $file = fopen("file.txt", "r");
while (($line = fgets($file)) !== false) {
  echo $line;
}
fclose($file);
11. Forms, Sessions & Cookies
  • Use $_POST and $_GET for form data.
  • Sessions: 
    session_start();
$_SESSION["user"] = "Alice";
  • Cookies: 
    setcookie("user", "Alice", time()+3600);
12. Best Practices & Resources
  • Always sanitize user input to prevent security issues.
  • Use prepared statements for databases.
  • Explore docs: php.net/manual/en/
  • Practice by building dynamic web pages and forms!
