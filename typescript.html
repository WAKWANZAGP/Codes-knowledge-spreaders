Important: What to Consider Before You Start Learning TypeScript
  • Mindset: TypeScript is JavaScript with static typing. Embrace types for safer, more robust code!
  • Tools: Install Node.js and TypeScript (npm install -g typescript), and use editors like VS Code.
  • Practice: Compile with tsc yourfile.ts and run with Node.js, or try the TypeScript Playground.
  • Ask Questions: Join our community for help and discussion.
  • Take Notes: Document types, interfaces, and common errors.
  • Explore: Try converting JavaScript projects to TypeScript, or building web apps and APIs.
  • Debug: Use console.log(), strict compiler options, and editor IntelliSense.

TypeScript Notes & Topics

1. Introduction to TypeScript
  • TypeScript is a typed superset of JavaScript that compiles to plain JS.
  • Great for large-scale, maintainable, and robust applications.
  • Files usually end with .ts.
2. Basic Syntax & Structure 
  • function greet(name: string): void {
  console.log("Hello, " + name + "!");
}
greet("TypeScript");
  • Comments: // single line, /* multi-line */
3. Variables and Data Types 
  • let age: number = 21;
const name: string = "Sam";
let isActive: boolean = true;
let ids: number[] = [1, 2, 3];
  • Types: number, string, boolean, array, any, void, null, undefined
4. Input and Output 
  • const readline = require('readline').createInterface({ input: process.stdin, output: process.stdout });
readline.question("Enter your name: ", (name: string) => {
  console.log(`Hello, ${name}!`);
  readline.close();
});
  • Use console.log() for output.
5. Control Flow (if, switch) 
  • if (age >= 18) {
  console.log("Adult");
} else {
  console.log("Minor");
}

switch(day) {
  case "Monday":
    console.log("Start of week");
    break;
  default:
    console.log("Other day");
}
6. Loops (for, while, for-of, for-in) 
  • for (let i = 0; i < 5; i++) {
  console.log(i);
}
let i = 0;
while (i < 5) { console.log(i++); }
for (let n of ids) { console.log(n); }
for (let key in obj) { console.log(key, obj[key]); }
7. Functions 
  • function add(a: number, b: number): number {
  return a + b;
}
const sqr = (x: number): number => x * x;
  • Supports optional, default, and rest parameters.
8. Arrays, Tuples & Enums 
  • let arr: number[] = [1, 2, 3];
let tup: [string, number] = ["Alice", 20];
enum Color { Red, Green, Blue }
  • Arrays are typed, tuples have fixed types, enums create readable sets.
9. Interfaces and Types 
  • interface Person {
  name: string;
  age: number;
}
const p: Person = { name: "Sam", age: 21 };
type Point = { x: number, y: number };
  • Interfaces and types define object shapes and contracts.
10. Classes and Objects 
  • class Dog {
  name: string;
  constructor(name: string) { this.name = name; }
  bark(): void { console.log("Woof!"); }
}
const d = new Dog("Max");
d.bark();
  • Supports inheritance, access modifiers (public, private, protected), static members.
11. Generics 
  • function identity(value: T): T {
  return value;
}
let n = identity(5);
let s = identity("hi");
  • Generics enable reusable, type-safe code components.
12. Best Practices & Resources
  • Use strict mode and type annotations for safety.
  • Explore docs: typescriptlang.org/docs
  • Practice by converting JS to TS and building apps.
