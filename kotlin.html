Kotlin Notes & Topics

1. Introduction to Kotlin
  • Kotlin is a statically-typed, JVM-based language by JetBrains, interoperable with Java.
  • Great for Android, backend, and multiplatform development.
  • Concise, null-safe, and supports both OOP and functional programming.
2. Program Structure
  • Kotlin programs start with fun main():
  • fun main() {
  println("Hello, Kotlin!")
}
3. Variables and Data Types
  • Declare variables with val (immutable) or var (mutable):
  • val name: String = "Alice"
var age = 21
val pi = 3.14
  • Types: Int, Double, Boolean, String, etc.
4. Input and Output
  • Output: println("Hello!")
  • Input (console): readLine() returns a String?
  • print("Enter your name: ")
val name = readLine()
println("Hi, $name!")
5. Control Flow (if, when) 
  • if (age >= 18) {
  println("Adult")
} else {
  println("Minor")
}

when (day) {
  "Monday" -> println("Start of week")
  else -> println("Other day")
}
6. Loops (for, while, do-while) 
  • for (i in 1..5) {
  println(i)
}
while (condition) { ... }
do { ... } while (condition)
7. Functions 
  • fun add(a: Int, b: Int): Int {
  return a + b
}
fun sqr(n: Int) = n * n
  • Supports default and named arguments, and higher-order functions.
8. Collections (Lists, Sets, Maps) 
  • val nums = listOf(1, 2, 3)
val fruits = setOf("apple", "banana")
val ages = mapOf("Alice" to 20, "Bob" to 25)
  • Mutable versions: mutableListOf, mutableSetOf, mutableMapOf
9. Classes and Objects 
  • class Person(val name: String, var age: Int) {
  fun greet() = println("Hi, I'm $name")
}
val p = Person("Alice", 20)
p.greet()
  • Use data class for value objects.
10. Null Safety
  • Variables are non-null by default. Use ? for nullable types.
  • var name: String? = null
if (name != null) {
  println(name.length)
}
  • Use !! to force non-null (be careful).
11. Lambdas & Higher-Order Functions 
  • val nums = listOf(1,2,3)
val doubled = nums.map { it * 2 }
val even = nums.filter { it % 2 == 0 }
12. Best Practices & Resources
  • Use descriptive names and idiomatic Kotlin (see Kotlin conventions).
  • Explore: kotlinlang.org/docs/home.html
  • Practice by building small apps or scripts!
