Important: What to Consider Before You Start Learning Rust
  • Mindset: Rust is safe, fast, and modern. Be ready for a new approach to memory and ownership.
  • Tools: Install Rust with rustup, use cargo for projects, and editors like VS Code, CLion, or Vim.
  • Practice: Try code in Rust Playground or your local setup.
  • Ask Questions: Visit our community for help and tips.
  • Take Notes: Record new syntax, error messages, and idioms.
  • Explore: Test memory, errors, and build small CLI tools or web servers.
  • Debug: Read error messages carefully, use dbg! and println! for output.

Rust Notes & Topics

1. Introduction to Rust
  • Rust is a compiled, statically-typed, memory-safe systems language.
  • Great for CLI tools, web servers, embedded, and performance-critical apps.
  • Files usually end with .rs.
2. Basic Syntax & Structure
  • All code is in functions, main entry point is fn main()
  • fn main() {
    println!("Hello, Rust!");
}
  • Comments: // single line, /* multi-line */
3. Variables and Data Types
  • Variables are immutable by default. Use mut to make mutable.
  • let x = 5;      // immutable
let mut y = 10; // mutable
let name: &str = "Sam";
let z: f64 = 3.14;
  • Types: i32, f64, bool, char, &str, etc.
4. Input and Output
  • Output: println!, dbg!
  • Input: use std::io and read_line:
  • use std::io;
fn main() {
    let mut input = String::new();
    io::stdin().read_line(&mut input).unwrap();
    println!("You typed: {}", input);
}
5. Control Flow (if, match) 
  • if x > 0 {
    println!("Positive");
} else if x == 0 {
    println!("Zero");
} else {
    println!("Negative");
}

match day {
    "Monday" => println!("Start of week"),
    _ => println!("Other day"),
}
6. Loops (for, while, loop) 
  • for i in 1..=5 {
    println!("{}", i);
}
let mut i = 0;
while i < 5 {
    println!("{}", i);
    i += 1;
}
loop {
    println!("Infinite!");
    break;
}
7. Functions 
  • fn add(a: i32, b: i32) -> i32 {
    a + b
}
println!("{}", add(2, 3));
  • Supports closures and higher-order functions.
8. Arrays, Vectors, and Slices 
  • let arr = [1, 2, 3];
let mut vec = vec![4, 5, 6];
vec.push(7);
  • Arrays have fixed size; vectors are resizable.
9. Structs and Enums 
  • struct Person {
    name: String,
    age: u32,
}
let p = Person { name: "Alice".to_string(), age: 20 };
enum Color { Red, Green, Blue }
  • Enums are used for pattern matching with match.
10. Ownership, Borrowing & Lifetimes
  • Rust enforces memory safety through ownership and borrowing.
  • let s = String::from("hi");
let r = &s; // borrow reference
// s is still valid
  • Use & for references, &mut for mutable references.
11. Error Handling 
  • fn divide(a: i32, b: i32) -> Result {
    if b == 0 {
        Err("No division by zero".to_string())
    } else {
        Ok(a / b)
    }
}
  • Use Option and Result types for safe error handling.
12. Best Practices & Resources
  • Use cargo for managing projects and dependencies.
  • Check docs: The Rust Book
  • Practice by building CLI tools and exploring error messages.
