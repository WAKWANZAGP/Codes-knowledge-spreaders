  • Take Notes: Document new syntax, patterns, and error messages.

Go Notes & Topics

1. Introduction to Go
  • Go (Golang) is a compiled language by Google for fast, reliable, and simple software.
  • Great for servers, cloud, CLI tools, and concurrent apps.
  • Easy to learn and deploy—cross-platform binaries.
2. Program Structure 
  • package main

import "fmt"

func main() {
  fmt.Println("Hello, Go!")
}
  • Every program starts with main package and main() function.
3. Variables and Data Types 
  • var name string = "Alice"
age := 20 // short form, type inferred
const Pi = 3.14
  • Types: int, float64, string, bool
  • Zero values: uninitialized variables have default values (0, "", false, etc).
4. Input and Output
  • Output: fmt.Println(), fmt.Printf()
  • Input: fmt.Scanln(&name)
  • var name string
fmt.Print("Enter your name: ")
fmt.Scanln(&name)
fmt.Println("Hello,", name)
5. Control Flow (if, else, switch) 
  • if age >= 18 {
  fmt.Println("Adult")
} else {
  fmt.Println("Minor")
}

switch day {
case "Monday":
  fmt.Println("Start of week")
default:
  fmt.Println("Other day")
}
6. Loops (for, while, range) 
  • for i := 0; i < 5; i++ {
  fmt.Println(i)
}

sum := 0
for sum < 10 {
  sum += 2
}
for i, v := range []string{"a", "b"} {
  fmt.Println(i, v)
}
  • No while or do-while; use for for everything.
7. Functions 
  • func add(a int, b int) int {
  return a + b
}
  • Multiple return values: 
    func swap(x, y string) (string, string) {
  return y, x
}
8. Arrays, Slices, and Maps 
  • var arr [3]int = [3]int{1,2,3}
s := []int{4,5,6}
m := map[string]int{"Alice": 21, "Bob": 22}
  • Use append() to grow slices, delete() for maps.
9. Structs and Methods 
  • type Person struct {
  Name string
  Age  int
}
func (p Person) Greet() {
  fmt.Println("Hi, my name is", p.Name)
}
  • Structs bundle data; methods give behavior.
10. Pointers 
  • x := 10
p := &x
fmt.Println(*p) // 10
  • Pointers let you modify values in place.
  • No pointer arithmetic.
11. Concurrency (goroutines, channels) 
  • go func() { fmt.Println("Hello from goroutine") }()
c := make(chan int)
go func() { c <- 5 }()
fmt.Println(<-c)
  • Use go for goroutines, chan for communication.
12. Error Handling & Resources 
  • val, err := someFunc()
if err != nil {
  fmt.Println("Error:", err)
}
  • Use defer for cleanup.
  • Explore: go.dev/doc
  • Practice by building and testing real Go programs!
