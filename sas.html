Important: What to Consider Before You Start Learning SAS
  • Mindset: SAS is a mainstay in statistical analysis and data management. Be ready to blend programming and statistics.
  • Tools: Install SAS (University Edition, OnDemand, or licensed) or use an online SAS Studio environment.
  • Practice: Type out every example, run it, and experiment with your own data.
  • Ask Questions: Join our community to discuss challenges and share code.
  • Take Notes: Record important procedures, options, and error messages.
  • Stay Curious: Try real datasets and different procedures as you learn.
  • Don’t Fear Errors: Every error is a learning opportunity. Read logs and search for solutions.

SAS Notes & Topics

1. Introduction to SAS
  • What is SAS? A language for advanced analytics, data management, and reporting.
  • Main uses: Statistical analysis, business intelligence, data management.
  • First steps: How to run a SAS program, using SAS Studio or Base SAS.
2. SAS Syntax & Structure
  • Statements end with a semicolon ;
  • DATA and PROC steps
  • Comments: * comment ; and /* comment */
3. Data Step Programming
  • Creating datasets with DATA and SET
  • Inputting data manually or from files
  • Using INFILE and INPUT statements
4. Variables and Data Types
  • Numeric and character variables
  • Variable attributes: length, format, informat
  • Assigning and manipulating variables
5. Importing and Exporting Data
  • Import data: PROC IMPORT, INFILE
  • Export data: PROC EXPORT, FILE, PUT
  • Reading/writing CSV, Excel, and other formats
6. Data Manipulation
  • Sorting: PROC SORT
  • Merging and joining: MERGE, BY
  • Subsetting: IF, WHERE
7. Functions and Expressions
  • Mathematical, character, date/time, and statistical functions
  • Using CALL routines
  • Expressions and assignment statements
8. Procedures (PROC Steps)
  • Common procs: PROC PRINT, PROC MEANS, PROC FREQ, PROC UNIVARIATE
  • Using options and statements within procs
  • Customizing output
9. Data Visualization
  • Creating plots: PROC SGPLOT, PROC GPLOT
  • Bar charts, histograms, scatter plots
  • Customizing titles, legends, and axes
10. Macro Programming
  • Defining macros: %MACRO, %MEND
  • Macro variables and %LET
  • Using macros for automation
11. Error Handling and Debugging
  • Reading the SAS log
  • Common errors and warnings
  • Using PUT statements for debugging
12. Advanced Topics & Best Practices
  • SQL in SAS: PROC SQL
  • Using libraries and external files
  • Best practices for documentation and organization
