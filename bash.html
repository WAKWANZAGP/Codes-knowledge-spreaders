Important: What to Consider Before You Start Learning Bash
  • Mindset: Bash is powerful for automation. Be careful, experiment, and don’t fear the terminal!
  • Tools: You need access to a Linux, macOS, or Windows (with WSL/Git Bash) terminal.
  • Practice: Try all commands in your own terminal. Start with simple scripts and build up.
  • Ask Questions: Use our community for help with errors and best practices.
  • Take Notes: Write down useful commands, options, and script snippets.
  • Explore: Read man pages (e.g., man ls) and official docs.
  • Be Cautious: Commands like rm -rf can be destructive. Always double-check before running unfamiliar scripts.

Bash Notes & Topics

1. Introduction to Bash
  • Bash (Bourne Again Shell) is a popular command-line interpreter for Unix/Linux systems.
  • Used for running commands, automating tasks, and writing scripts.
  • Bash scripts are plain text files with .sh extension, run with bash script.sh or ./script.sh.
2. Basic Commands
  • ls: List files
  • pwd: Show current directory
  • cd: Change directory
  • cp, mv, rm: Copy, move, and remove files
  • man [command]: Read manual for a command
3. Creating and Running Scripts
  • Start scripts with a shebang: #!/bin/bash
  • Make a script executable: chmod +x script.sh
  • Run: ./script.sh
4. Variables
  • Assign: name="Alice" (no spaces before/after =)
  • Use: echo $name
  • Command substitution: today=$(date)
5. Input and Output
  • Read user input: read username
  • Print: echo "Hello, $username!"
  • Redirect output: ls > files.txt, append: >>
6. Conditionals (if, else, elif) 
  • if [ "$name" = "Alice" ]; then
  echo "Hello, Alice!"
else
  echo "Hi, $name!"
fi
  • Comparison: -eq, -ne, -lt, -gt for numbers
7. Loops (for, while, until) 
  • for i in 1 2 3
do
  echo $i
done
  • While loop: while [ condition ]; do ...; done
  • Until loop: until [ condition ]; do ...; done
8. Functions 
  • greet() {
  echo "Hello, $1!"
}
greet "Alice"
  • Use $1, $2 for arguments.
9. File Operations
  • Test if file exists: [ -f filename ]
  • Read files line by line: 
    while read line; do
  echo $line
done < file.txt
  • Wildcards: *.txt
10. Scripting Best Practices
  • Add comments with #
  • Use set -e to stop on errors
  • Validate scripts with shellcheck
  • Always test scripts on sample data first
11. Useful Bash Tricks
  • Use history and !! to repeat last command
  • Pipe commands: ls | grep "data"
  • Combine with cron for automation
