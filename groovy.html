Groovy Notes & Topics

1. Introduction to Groovy
  • What is Groovy? A dynamic, optionally-typed language for the JVM, designed for productivity.
  • Use cases: Scripting, testing (Spock), automation, and even building applications.
  • How to run Groovy scripts: groovy myscript.groovy or groovyConsole
2. Syntax & Variables
  • No semicolons required (optional).
  • Variables: def x = 10, String name = "Alice"
  • Dynamic and static typing.
3. Input and Output
  • Printing: println "Hello, world!"
  • User input: def name = System.console().readLine('Enter your name: ')
4. Control Flow (if, else, switch)
  • Conditional statements: if, else if, else, switch
  • Comparison operators: ==, !=, <, >
  • Example:
    if (age >= 18) {
      println "Adult"
    } else {
      println "Minor"
    }
5. Loops (for, while, each)
  • for (i in 1..5) { ... } — Iterate over ranges or collections
  • while (condition) { ... }
  • Collection methods: each { ... }
  • Break and continue
6. Methods (Functions)
  • Defining: def greet(name) { println "Hello, $name" }
  • Calling: greet("Alice")
  • Return values: return x + y
  • Default parameters
7. Lists, Maps, and Ranges
  • List: def nums = [1, 2, 3]
  • Map: def person = [name: 'Alice', age: 25]
  • Range: def range = 1..10
  • Common operations: each, find, collect
8. Classes and Objects
  • Defining a class: class Person { String name; int age }
  • Creating objects: def p = new Person(name: 'Alice', age: 25)
  • Properties, methods, constructors
9. File Handling
  • Reading files: new File('file.txt').eachLine { println it }
  • Writing files: new File('file.txt').text = "Hello"
  • Appending: new File('file.txt') << "More text"
10. Error Handling
  • Try-catch blocks: try { ... } catch (Exception e) { ... }
  • Throwing exceptions: throw new Exception("Error message")
  • Understanding and fixing common errors
