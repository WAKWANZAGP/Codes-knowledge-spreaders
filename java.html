Java Notes & Topics

1. Introduction to Java
  • Java is a statically-typed, object-oriented language known for portability and scalability.
  • Write once, run anywhere: Java programs run on the Java Virtual Machine (JVM).
  • Popular for enterprise, web, and Android apps.
2. Structure of a Java Program
  • Every Java file has at least one class. The main method is the entry point.
  • public class HelloWorld {
  public static void main(String[] args) {
    System.out.println("Hello, Java!");
  }
}
3. Variables and Data Types
  • Common types: int, double, String, boolean, char
  • int age = 21;
double temp = 36.6;
String name = "Sam";
boolean isActive = true;
4. Input and Output
  • Output: System.out.println("Hello!");
  • Input (console): Scanner sc = new Scanner(System.in); String input = sc.nextLine();
  • Don't forget to import java.util.Scanner;
5. Control Flow (if, else, switch) 
  • if (age >= 18) {
  System.out.println("Adult");
} else {
  System.out.println("Minor");
}
                
  • switch(day) {
  case "Monday":
    System.out.println("Start of week");
    break;
  default:
    System.out.println("Other day");
}
6. Loops (for, while, do-while, for-each) 
  • for (int i = 0; i < 5; i++) {
  System.out.println(i);
}
while (condition) { ... }
do { ... } while (condition);
for (String name : names) { ... }
7. Methods (Functions) 
  • public static int add(int a, int b) {
  return a + b;
}
  • Methods can be static (called on the class) or instance (called on objects).
8. Arrays and ArrayLists 
  • int[] arr = {1, 2, 3};
System.out.println(arr[0]);
                
  • import java.util.ArrayList;
ArrayList<String> list = new ArrayList<>();
list.add("Alice");
9. Classes and Objects 
  • public class Dog {
  String name;
  void bark() {
    System.out.println("Woof!");
  }
}
Dog d = new Dog();
d.name = "Max";
d.bark();
  • Understand fields, methods, constructors, and instantiation.
10. Exception Handling 
  • try {
  int x = Integer.parseInt("abc");
} catch (NumberFormatException e) {
  System.out.println("Error: " + e.getMessage());
} finally {
  System.out.println("Done!");
}
  • Handle exceptions for robust programs.
11. Advanced Features
  • Inheritance, interfaces, abstract classes, generics, lambda expressions, streams.
  • Explore JavaFX or Swing for GUIs, and Spring Boot for web apps.
12. Best Practices & Resources
  • Use meaningful class, method, and variable names (camelCase, PascalCase).
  • Keep code DRY, modular, and well-commented.
  • Explore docs: docs.oracle.com/javase/tutorial/
  • Practice by solving problems and building apps!
