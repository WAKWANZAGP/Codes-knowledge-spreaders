R Notes & Topics

1. Introduction to R
  • R is a language for data analysis, statistics, and visualization.
  • Widely used in academia, research, and industry.
  • Files usually end with .R or .Rmd (R Markdown).
2. Basic Syntax & Structure 
  • # This is a comment
x <- 5
y = 2 * x
print(y)
  • Use <- or = for assignment. R is case-sensitive.
3. Vectors, Lists, and Data Frames 
  • vec <- c(1, 2, 3)
lst <- list(a=1, b="hi")
df <- data.frame(name=c("Alice","Bob"), age=c(20,21))
df$name
  • Vectors are the basic data structure in R.
4. Input and Output
  • Output: print(), cat()
  • Input: readline(prompt="Enter your name: ")
  • name <- readline(prompt="Enter your name: ")
cat("Hello,", name, "!\n")
  • Read data from CSV: read.csv("file.csv")
5. Control Flow (if, else, switch) 
  • if (age >= 18) {
  print("Adult")
} else {
  print("Minor")
}

switch(day,
  "Monday" = print("Start of week"),
  print("Other day")
)
6. Loops (for, while, repeat) 
  • for (i in 1:5) {
  print(i)
}
while (x < 10) {
  x <- x + 1
}
repeat {
  print(x)
  if (x > 10) break
}
7. Functions 
  • add <- function(a, b) {
  return(a + b)
}
add(2, 3)
  • Functions are first-class and can be anonymous.
8. Packages and Libraries
  • Install: install.packages("dplyr")
  • Load: library(dplyr)
  • Popular: ggplot2 for plots, dplyr for data manipulation, tidyr for data tidying.
9. Plotting and Visualization 
  • x <- 1:10
y <- x^2
plot(x, y, type="b", col="blue")
  • For advanced: library(ggplot2)
10. Data Import/Export 
  • data <- read.csv("file.csv")
write.csv(data, "out.csv")
  • R can handle CSV, Excel, JSON, and more.
11. Statistical Analysis 
  • mean(c(1,2,3))
summary(df)
lm(y ~ x, data=df)
  • Many built-in functions for stats, regression, and hypothesis testing.
12. Best Practices & Resources
  • Keep code tidy and use comments.
  • Explore docs: CRAN Manuals
  • Practice by analyzing real datasets and visualizing data!
