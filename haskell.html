Important: What to Consider Before You Start Learning Haskell
  • Mindset: Haskell is pure, lazy, and functional. Be ready to think differently about computation!
  • Tools: Install the Haskell Platform or GHCup, and use an editor like VS Code or Emacs with Haskell plugins.
  • Practice: Try code in ghci (the interactive REPL) as you learn.
  • Ask Questions: Reach out in our community for help and discussion.
  • Take Notes: Write down new patterns, type signatures, and error messages.
  • Explore: Haskell is great for math, parsing, and concurrency—try small projects!
  • Debug: Read error messages fully—Haskell is strict about types, but the errors are helpful.

Haskell Notes & Topics

1. Introduction to Haskell
  • Haskell is a statically-typed, purely functional programming language with lazy evaluation.
  • Great for math, language processing, and concurrent systems.
  • Files have .hs extension.
2. Basic Syntax & GHCi
  • Run ghci for interactive exploration.
  • Simple expressions: 
    Prelude> 2 + 3 * 4
14
Prelude> let x = 5
Prelude> x * 2
10
  • Comments: -- single line, {- multi line -}
3. Data Types & Type Signatures
  • Common types: Int, Integer, Float, Double, Char, Bool, String
  • Type signatures: add :: Int -> Int -> Int
  • add :: Int -> Int -> Int
add a b = a + b
4. Functions and Pattern Matching
  • Functions are first-class. Pattern matching makes code concise.
  • factorial 0 = 1
factorial n = n * factorial (n-1)
  • Guards: 
    abs x | x >= 0    = x
      | otherwise = -x
5. Lists and Tuples 
  • nums = [1,2,3]
names = ["Alice", "Bob"]
pair = (2, "hi")
head nums -- 1
tail nums -- [2,3]
  • List comprehensions: [x*2 | x <- [1..5]]
6. Higher-Order Functions
  • Functions can take other functions as arguments or return them.
  • map (\x -> x * 2) [1,2,3] -- [2,4,6]
filter even [1..10] -- [2,4,6,8,10]
7. Recursion
  • Most loops in Haskell are written using recursion.
  • sumList [] = 0
sumList (x:xs) = x + sumList xs
8. Algebraic Data Types 
  • data Color = Red | Green | Blue
data Person = Person String Int
  • Pattern match on custom types to extract data.
9. Typeclasses & Instances
  • Typeclasses define common interfaces, like Eq, Show, Ord.
  • instance Eq Color where
  Red == Red = True
  _ == _ = False
  • Use deriving to auto-implement common typeclasses.
10. IO and the Main Function 
  • main = do
  putStrLn "What's your name?"
  name <- getLine
  putStrLn ("Hello, " ++ name)
  • IO in Haskell is handled with do blocks and monads.
11. Modules & Imports
  • Split code into modules for organization and reuse.
  • module MyModule (foo) where
foo = "bar"

import Data.List (sort)
12. Best Practices & Resources
  • Write clear function/type signatures and use descriptive names.
  • Read: haskell.org/documentation
  • Practice by solving problems and building small projects.
  • Explore Haskell for parsing, math, and concurrent programming.
