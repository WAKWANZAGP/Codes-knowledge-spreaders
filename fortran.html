Fortran Programming Class
Important: What to Consider Before You Start Learning Fortran
  • Mindset: Fortran is used for numerical and scientific computing. Be ready for structured, procedural code and attention to detail.
  • Tools: Install a Fortran compiler (like GNU Fortran/gfortran) and use a simple code editor or IDE (e.g., VS Code, Code::Blocks).
  • Practice: Type every example yourself. Compile, run, and modify code to see changes.
  • Ask Questions: Join our community to discuss challenges and share code.
  • Take Notes: Jot down syntax, common errors, and compiler messages.
  • Stay Curious: Try small scientific or mathematical programs as you learn.
  • Don’t Fear Errors: Errors are normal. Read messages and search for solutions.

Fortran Notes & Topics

1. Introduction to Fortran
  • What is Fortran? A pioneering language for numerical and scientific computation.
  • Main uses: Engineering, simulations, physics, high-performance computing.
  • How to run Fortran: Writing, compiling, and executing code.
2. Program Structure
  • Program units: program, subroutine, function, module
  • Basic structure: program name ... end program name
  • Statements and indentation
3. Variables and Data Types
  • Declaring variables: integer :: x, real :: y
  • Types: INTEGER, REAL, DOUBLE PRECISION, COMPLEX, CHARACTER, LOGICAL
  • Constants and parameters: parameter
4. Input and Output
  • Reading: read *
  • Writing: print *, write *
  • Formatting I/O
5. Arithmetic and Logical Operators
  • Arithmetic: +, -, *, /, **
  • Logical: .AND., .OR., .NOT.
  • Relational: .EQ., .NE., .GT., .LT., .GE., .LE.
6. Control Flow (If, Select Case)
  • Conditional statements: if, else if, else, end if
  • Select case for multiple choices
  • Example:
    if (x >= 0) then
      print *, "Positive"
    else
      print *, "Negative"
    end if
7. Loops (Do, Do While, Exit, Cycle)
  • Do loop: do i = 1, 10 ... end do
  • Do while loop: do while (condition) ... end do
  • Exit and cycle for loop control
8. Arrays and Matrices
  • Declaring arrays: integer, dimension(10) :: arr
  • Multi-dimensional arrays
  • Array operations and intrinsic functions
9. Functions and Subroutines
  • Functions: function name(args) ... end function name
  • Subroutines: subroutine name(args) ... end subroutine name
  • Passing arguments and return values
10. Modules and Scope
  • Modules for reusable code: module ... end module
  • Using use statement to import modules
  • Scope rules: public/private
11. File Handling
  • Opening/closing files: open, close
  • Reading/writing files: read, write
  • Error handling with iostat
12. Debugging and Best Practices
  • Common errors and warnings
  • Debugging tips: print statements, using IDEs
  • Best practices: code style, comments, modular design
