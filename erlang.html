Erlang Programming Class
Important: What to Consider Before You Start Learning Erlang
  • Mindset: Erlang is designed for building concurrent, fault-tolerant, distributed systems. Embrace functional programming and message passing.
  • Tools: Install Erlang/OTP (erlang.org) and use the erl shell or editors like VS Code with extensions.
  • Practice: Type and run every example. Experiment with functions, processes, and modules.
  • Ask Questions: Join our community or Erlang forums to share code and discuss problems.
  • Take Notes: Write down useful patterns, error messages, and OTP concepts.
  • Stay Curious: Try building small concurrent programs or simple servers as you learn.
  • Don’t Fear Errors: Debugging concurrency is a skill. Learn to read crash reports and use tracing tools.

Erlang Notes & Topics

1. Introduction to Erlang
  • What is Erlang? A functional, concurrent language designed for telecom and distributed systems.
  • Main uses: Messaging, servers, distributed apps, fault-tolerant systems.
  • How to run the shell and scripts: erl, escript.
2. Syntax and Expressions
  • Atoms, numbers, strings, tuples, lists, maps.
  • Pattern matching and variables (single assignment).
  • Expression endings: period (.) in shell.
3. Functions and Modules
  • Defining functions: fun/arity, myfun(X) -> ... end.
  • Modules: -module(name)., -export([fun/arity]).
  • Calling functions and loading modules.
4. Pattern Matching and Guards
  • Pattern matching in variable assignments and function arguments.
  • Guards: when keyword, guard expressions.
  • Matching tuples, lists, and more.
5. Lists, Tuples, and Maps
  • Creating and working with lists: [1,2,3], head/tail, list comprehensions.
  • Tuples: {ok, Value}
  • Maps: #{key => value}
6. Recursion and Higher-Order Functions
  • Recursive functions and base cases.
  • Using map, foldl, filter from lists module.
  • Anonymous functions (fun ... end).
7. Concurrency and Processes
  • Spawning processes: spawn(Fun), spawn(Module, Function, Args)
  • Sending (!) and receiving messages (receive ... end).
  • Process identifiers (PIDs).
8. Error Handling and Supervision
  • try/catch and after.
  • Process monitoring and links.
  • Supervision trees (OTP basics).
9. File and IO Handling
  • Reading/writing files: file:read_file/1, file:write_file/2.
  • IO functions: io:format/2, io:get_line/1.
  • Error handling with file/IO.
10. Macros and Records
  • Defining macros: -define(NAME, VALUE).
  • Using records: -record(name, {field1, field2}).
  • Accessing and updating record fields.
11. Modules and Code Organization
  • Organizing code into modules and applications.
  • Using include files and header files.
  • Application structure and dependencies.
12. OTP Framework and Best Practices
  • What is OTP? GenServer, Supervisor, Application behaviour.
  • Implementing a simple GenServer.
  • Best practices for reliability and maintainability.
